Что важно знать из истории (чтобы не наступить снова):
- TypeScript закреплён на `^5.9.3`, 7.x ломает `vue-tsc`. Не поднимать.
- MapLibre 6 грузит worker отдельным модулем; Vite его не отдаёт. В `MapView.vue` worker импортируется через `maplibre-gl/dist/maplibre-gl-worker.mjs?worker&url` и передаётся в `setWorkerUrl`. Без этого событие `load` не приходит и сканер не стартует. Не убирать.
- Подписи на карте используют шрифт `Noto Sans Regular` — единственный на сервере стилей openfreemap. Другие шрифты дают 404 на каждый глиф.
- Скорость подсаженных рейсов считается от времени: самый длинный штрих буквы рисуется 1.75 мин при любом масштабе (`PLANT_STROKE_MINUTES` в `MockSource.ts`). Старое «1200 км/ч» из спеки отменено.
- Легенда рейсов (авиакомпания, борт, аэропорты) берётся из отдельного генератора случайных чисел `mulberry32(seed + 1)`, чтобы не сдвигать геометрию подсадки. Тесты подсадки на зёрнах 4, 5, 6 в `MockSource.plant.test.ts` зависят от этого.
- Детекторы, пороги, шум подсадки (5%, ±2°) и STROKES менять нельзя — только STROKES, если подсаженная буква не находится.
- В `useScanner.ts` есть защита от повторного входа (`run`, `inFlight`, `restartPending`) — не упрощать, там были два раунда правок.
- Иконки самолётов рисуются на canvas в `MapView.vue` (`makePlaneIcon`), экстраполируются каждые 100 мс по курсу и скорости; трек без обновлений дольше 60 с иконкой не рисуется.
- Фото для карточки — Wikimedia Commons API без ключа (`src/data/photos.ts`), кэш на сессию, ошибки дают пустой список.
- FR24 `full` живьём не проверен (нет ключа): поля по документации, см. `Fr24Source.test.ts`.
- Отладку в браузере без ручного участия я делал через headless Chrome + DevTools Protocol: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --use-angle=metal --remote-debugging-port=9333` и небольшой Node-скрипт с WebSocket (навигация, ожидание, `Runtime.evaluate`, `Page.captureScreenshot`). Без `--use-angle=metal` (или swiftshader) WebGL2 недоступен и карта падает.

Ручная проверка, которую я ещё не прошёл (план 2, Task 9, Step 4):
1. Карта открывается на zoom 8 вокруг Москвы, десятки жёлтых самолётов плавно ползут по курсу.
2. Отдалить карту на два шага — бортов больше (до 120), приблизить — меньше (не меньше 30). Старые иконки после смены масштаба пропадают в течение минуты.
3. Курсор над самолётом — рука. Клик: самолёт краснеет, справа карточка с позывным, чипом борта, авиакомпанией, двумя фото, IATA и городами, блоком «Хуёвость 0%».
4. «Слово», через 2–3 минуты клик по красному штриху Х: «Нарисовал букву Х на NN%», «В составе слова ХУЙ, …».
5. Крестик и клик по пустой карте закрывают карточку; клик по другому самолёту переключает.
6. Подсаженный борт долетел и исчез — карточка закрылась сама.
7. В консоли нет ошибок.

Открытые вопросы и отложенные мелочи (не чинить, пока я не скажу):
- Пункт из первой итерации: «Эталонный» для подсаженного слова почти недостижим (80–85 с шумом), потому что `size` букв считается по-разному. Калибровка спеки.
- Мелочи из реестров: дубль `KM_PER_DEG` в двух файлах; неудачные запросы фото кэшируются на сессию; фото не перезапрашиваются, если легенда пришла после выбора; мелькание «фото не нашлось» до загрузки; нет тестов на сортировку в `flightStats` и на перезапись `info` в `TrackStore`.
- Зависание страницы, о котором я говорил раньше, не воспроизвелось ни в одном прогоне (61 кадр/с при перетаскивании и зуме). Если повторится — нужны браузер, время до зависания и консоль.

Правила работы:
- Отвечай по-русски, коротко, без транслита.
- Новые функции — через `superpowers:brainstorming` → спека → `superpowers:writing-plans` → `superpowers:subagent-driven-development`: свежий субагент на задачу, ревью после каждой, коммит после каждой, задачи строго последовательно.

- В коммитах последняя строка после пустой: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

- В `main` не сливать без моего слова.
